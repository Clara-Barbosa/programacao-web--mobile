
# 🌐 Programação Web Mobile

Repositório destinado às atividades, exercícios e projetos desenvolvidos durante a disciplina de **Programação Web Mobile**.

Ao longo do semestre, este repositório será utilizado para organizar e armazenar as práticas realizadas em sala de aula e as atividades propostas pelo professor.

## 🎯 Objetivo

Aplicar na prática os conceitos estudados na disciplina, desenvolvendo páginas e aplicações web com foco em organização, estilização, componentização e navegação entre páginas.

## 🚀 Tecnologias

Durante a disciplina, poderão ser utilizadas tecnologias como:

* React
* Next.js
* JavaScript
* HTML / JSX
* CSS
* Git
* GitHub
* Vercel

## 📁 Organização

As atividades serão separadas em pastas dentro deste repositório, permitindo manter os exercícios organizados conforme o avanço da disciplina.

Exemplo:

```text
programacao-web--mobile/
├── react-01/
├── react-02/
├── react-03/
├── ...
├── LICENSE
└── README.md
```

## 📚 Sobre o repositório

Este repositório será atualizado ao longo do semestre conforme novos conteúdos, exercícios e projetos forem desenvolvidos na disciplina de **Programação Web Mobile**.
